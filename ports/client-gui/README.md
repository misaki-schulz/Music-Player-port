# Проверка интерфейса в Minecraft

Сценарий запускает клиент Minecraft, работает с кнопками и полями Music Player и сохраняет скриншоты. Он проверяет плейлисты, поиск, импорт WAV, сортировку, настройки и управление воспроизведением.

Тест подставляет ответ системного окна выбора файла. Вход в музыкальные сервисы, доступность этих сервисов и качество звука нужно проверять отдельно.

## Запуск в Windows

Понадобятся Python 3, PowerShell 7, JDK для выбранной версии Minecraft и драйвер с поддержкой OpenGL. Выполняйте команды из корня репозитория.

```powershell
python ports/client-gui/build_agent.py
python ports/client-gui/run_matrix.py --loader forge --version 1.20.1
python ports/client-gui/run_matrix.py --loader neoforge --version 1.21.1
```

Без `--loader` и `--version` сценарий проходит всю матрицу. `--resume` пропускает профили, которые уже прошли проверку с теми же исходниками и агентом. `--no-build` использует готовую сборку.

Результаты записываются в `.cache/client-tests/matrix-results.json`. Логи и скриншоты лежат в подкаталогах профилей. [Последний сохранённый отчёт в репозитории](last-results.md) относится к port.10.
