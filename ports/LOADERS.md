# Forge и NeoForge — port.10

Это дополнительные варианты существующего port.10. В одну установку Minecraft
ставьте один JAR Music Player, соответствующий загрузчику и версии игры.
Forge/NeoForge-варианты содержат собственные адаптеры событий и не требуют Fabric API.
Аудиодвижок, поиск, сортировка, эквалайзер, плейлисты и вход в YouTube сохранены.

## Сборка

Для команд сборки и проверки нужен Python 3.11 или новее.

В Windows главное меню `build-menu.bat` содержит пункт `N` для Forge/NeoForge.
На Linux/macOS используйте `sh build-menu.sh` или команды ниже.

```powershell
python ports/loader_cli.py --list
python ports/loader_cli.py --loader forge --version 1.20.1
python ports/loader_cli.py --loader neoforge --version 1.21.2
python ports/loader_cli.py --loader neoforge --all
python ports/loader_cli.py --all
```

Сборки выполняются последовательно; после каждой проверяется готовый JAR.
Выход: `dist/port.10/music_player-<loader>-<Minecraft>-2.7.1.351.port.10.jar`.
Метаданные и контрольные суммы нативных портов находятся в `loader-manifest.json`
и `LOADER-SHA256SUMS`. Профили перечислены в `loader-targets.json`.
Fabric 1.21.1 собирается командой `python ports/release_cli.py --group 1.21.1`.

Gradle для Forge 1.21.1/1.21.3 запускается на JDK 21; для Forge 1.20.1,
всех NeoForge и Fabric — на JDK 25. Для компиляции нужны JDK 17, 21 и 25.
Windows-скрипт ищет JDK в `%JAVA_HOME%`, `%ProgramFiles%/Java` и `%USERPROFILE%/.jdks`.
На других системах задайте подходящий `JAVA_HOME` перед командой сборки.

## Устройство портов и проверка

Профили `forge-*` / `neoforge-*` переиспользуют Minecraft-зависимые общие классы
и аудиомодули соответствующего профиля Fabric. `loader-common` содержит конфигурацию,
загрузку вложенных библиотек и запуск/остановку аудиодвижка. В каждом профиле
находятся нативные точка входа, регистрация клавиш и обработчики экрана, HUD и тиков.
Для Forge и старого NeoForge итоговый shaded JAR проходит SRG-remapping.
Современный NeoForge использует официальные имена Minecraft.
Начиная с 1.21.9 вложенные библиотеки читаются через `JarContents` нового FML;
временные копии исходных ресурсов удаляются при завершении JVM.

`package_loaders.py` проверяет метаданные, точную версию Minecraft, отсутствие
ссылок на Fabric, допустимый байткод Java, 37 вложенных аудиобиблиотек, сохранённые
vendor-зависимости, ресурсы, лицензии и байткод маршрутизации YouTube.
Эти проверки не заменяют запуск Minecraft: клавиши, HUD, вход в YouTube и
воспроизведение следует проверить в клиенте с соответствующим загрузчиком.
