# Music Player port.11 for Minecraft 26.1, 26.1.1, 26.1.2

This Fabric profile requires Java 25, Fabric Loader 0.19.5 or newer, and the Fabric API listed for your Minecraft version in the [build matrix](../README.md).

From the repository root, run this command to build and package the profile.

```bash
python ports/release_cli.py --group 26.1-26.1.2
```

The packaged JAR is written to `dist/port.11/`. See the [project README](../../README.md) for installation and the [changelog](CHANGELOG.md) for release history.
