# Проверки port.10.2

Все 50 сочетаний версии Minecraft и загрузчика собраны успешно: 17 Fabric,
16 Forge и 17 NeoForge. Все 33 набора автономных регрессий прошли успешно:
сортировка, маршрутизация аудио и SoundCloud в каждом из 11 исходных профилей.
Проверки упаковки релизных JAR завершились успешно.

Полные результаты сборок: [build-results.json](build-results.json).

Все 16 версий Forge прошли сценарий GUI и загрузки WAV в настоящем клиенте Minecraft.
На 13 версиях ForgeGradle 7 загружался готовый релизный JAR с вложенными
аудиобиблиотеками. На трёх старых Forge запускались скомпилированные исходники
в dev-клиенте. Дальнейшие запуски клиентов остановлены по просьбе сопровождающего.

Подробности: [forge-gui-results.json](forge-gui-results.json).

Вход в сторонние сервисы, живое воспроизведение SoundCloud/YouTube, качество звука,
игровой мир и интерфейс системного диалога выбора файлов этим сценарием не проверяются.
Регрессия SoundCloud использует локальную HTTP-модель API и настоящую аудиобиблиотеку.
